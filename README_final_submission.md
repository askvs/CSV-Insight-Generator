<h3 id="project1">Project 1: AI-Powered Insight Generator</h3>

<h4 id="project-introduction">Project Introduction</h4>
<p>
  <strong>AI-Powered Insight Generator</strong> is an interactive web-based data analytics platform designed to bridge natural language understanding with dynamic data analysis. Built with <strong>Streamlit</strong> and powered by <strong>Groq LLMs</strong>, the application allows users to upload any CSV dataset and query it conversationally. An autonomous AI agent translates user queries into Python code, runs the analysis in a secure sandbox, renders interactive Matplotlib visualizations, and generates downloadable executive PDF reports.
</p>

<h4 id="technologies-used">Technologies Used</h4>
<ul>
  <li><strong>Frontend:</strong> Streamlit</li>
  <li><strong>LLM Backend:</strong> Groq API (Qwen, GPT-OSS models)</li>
  <li><strong>Data Processing & Visualization:</strong> Pandas, NumPy, Matplotlib</li>
  <li><strong>Document Generation:</strong> ReportLab (PDF)</li>
</ul>

<h4 id="roles-and-responsibilities">Roles and Responsibilities</h4>
<ul>
  <li>Designed and implemented the autonomous agentic loop with tool calling for code generation and execution.</li>
  <li>Built a secure sandboxed execution environment with restricted imports for safe data analysis.</li>
  <li>Developed the responsive Streamlit chat UI with dataset profiling and dynamic chart rendering.</li>
  <li>Implemented automated executive PDF report compilation and deployed the application to Streamlit Community Cloud.</li>
</ul>
